# BP Inspector

**Blueprint Static Analysis & Linting Tool for Unreal Engine**

Make your Blueprints clean. 30 inspection rules across 4 categories help you find bugs, performance issues, and code smells before they become problems.

## Features

- 30 inspection rules: Code Quality, Best Practices, Performance, Style
- One-click project-wide scanning
- Navigate directly to problem nodes
- Filter by severity, rule, and text search
- Content Browser and Blueprint Editor integration
- Data Validation on save with clickable messages
- CI/CD commandlet with JSON export
- Fully configurable thresholds per rule
- C++ core with full source code
